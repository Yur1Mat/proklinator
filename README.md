# Проклимёт

Telegram Mini App для шуточных проклятий. Пользователь вводит имя и причину, после чего получает один из 20 вариантов результата. Два одинаковых варианта не выпадают подряд.

## Приватность

Черновик формы и последние 20 результатов сохраняются только в `localStorage` браузера на устройстве пользователя. Приложение не отправляет введённые данные на сервер и не использует базу данных.

## Публикация

После каждого пуша в `master` или `main` GitHub Actions публикует статические файлы на GitHub Pages. В настройках репозитория нужно один раз выбрать **Settings → Pages → Source: GitHub Actions**.

Адрес после публикации: `https://yur1mat.github.io/proklinator/`.

## Подключение к Telegram

1. Откройте `@BotFather` и выполните `/newbot`, если бот ещё не создан.
2. Выполните `/mybots`, выберите бота, затем **Bot Settings → Menu Button → Configure menu button**.
3. Передайте HTTPS-адрес GitHub Pages и название кнопки, например `Проклясть`.
4. При необходимости выполните `/setmenubutton` и повторно укажите тот же адрес.
5. Откройте бота и нажмите кнопку меню — Mini App откроется внутри Telegram.

Токен бота для текущей версии не нужен: приложение полностью клиентское. Не добавляйте токен в репозиторий.

## Локальный запуск

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер в корне проекта.
